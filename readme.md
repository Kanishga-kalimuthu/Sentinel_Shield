# SentinelShield : AI-Based Multimodal Heavy Vehicle Security System

## About the Project
SentinelShield is an AI-based multimodal security system
designed for heavy vehicles.

## Technologies Used
- Python
- HTML
- CSS
- JavaScript
- MySQL
- Arduino IDE

## Database
The project uses MySQL for storing and managing data.

Database SQL file: `database/sentinelshield.sql`

## Project Structure
- python/ - Python source code
- html/ - HTML files
- css/ - CSS stylesheets
- javascript/ - JavaScript files
- arduino/ - Arduino source code
- database/ - MySQL database files

## Installation and Setup
1. Download or clone this repository.
2. Install the required Python packages.
3. Set up the MySQL database using the SQL file.
4. Configure your database connection.
5. Run the project.
